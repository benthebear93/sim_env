# Flange adapter

The source tactile preview models the adapter as a cylinder with radius 32 mm
and thickness 20 mm along UR `tool0` +z. Its rear face is at tool0 z=0.
No measured CAD, bolt pattern, mass, or inertia was supplied.

The reusable generated geometry is `models/components/flange_adapter.xml`.
Edit `configs/bench.json` and regenerate with `scripts/build_scene.py`.
The initial density assumption is 2700 kg/m³ (aluminum).
